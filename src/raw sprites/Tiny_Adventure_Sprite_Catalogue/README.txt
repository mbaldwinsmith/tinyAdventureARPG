Tiny Adventure Sprite Catalogue

Extract this ZIP and open index.html in a browser. No server, package install or network connection is needed.

Files:
  SPRITE_INDEX.md — findings, source precedence, companion sets and all 716 image/sheet entries
  sprite-index.csv — 716 deduplicated image/sheet rows
  archive-inventory.csv — every one of the 1,466 file occurrences
  sprite-catalogue.json — full relationships, source hashes, suggested uses and framing notes
  previews/ — original-resolution images, copied unchanged for inspection
  contact-sheets/ — all 20 reviewed contact sheets

Scope: a semantic catalogue of PNG sheets, not a finished per-frame atlas. Frame timings, tile adjacency, hitboxes, attachment offsets and individual meanings inside unlabeled mixed sheets require a separate implementation pass. Related links are compatibility/design groupings, not proof that one asset requires every other linked image.

The paid artwork belongs to Vryell; the user owns the packs. Keep this catalogue and included previews within the authorised project workflow. Source files in GitHub were only read; no repository changes were made.
